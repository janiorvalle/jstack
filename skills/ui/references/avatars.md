# Avatars

Use these rules for profile photos, user thumbnails, testimonial people, comments, team members, and overlapping avatar groups.

- Use a real photo from the project when there is one, otherwise a generated portrait, saved as a file with an extension like `avatar-1.webp`
- On light surfaces use `outline-1 -outline-offset-1 outline-black/5` or `outline-black/10`. On dark surfaces use `outline-white/10`
- Stacked or overlapping avatar groups get a 2px `ring` in the background color (e.g. `ring-2 ring-white`)
