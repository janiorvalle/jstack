# Footers

Rules for page footers: footer logos, footer navigation, footer links, and social media icons.

## Design rules

- Logo height between `h-5` and `h-7`
- Footer links use `font-normal`
- Social media icons are at least `text-gray-600`. Never `text-gray-400` or lighter

## Coding rules

- Use the [placeholder content](placeholder-content.md) logo endpoint when no logo file is provided. Never build logos from scratch with HTML or icons
