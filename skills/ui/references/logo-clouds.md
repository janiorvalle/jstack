# Logo clouds

Rules for logo grids, customer logos, partner logos, trust bars, client rows, and any collection of brand marks.

- Spread logos evenly across rows when they wrap. Never leave an unbalanced last row. Use a grid or layout that splits them as evenly as possible (3+3 instead of 5+1 for 6 logos)
- A logo cloud right under a hero is part of the hero, so match the hero's alignment. A left-aligned hero gets a left-aligned logo cloud label and logos
