# Copywriting

Use these rules for headings, taglines, subtitles, descriptions, labels, list items, button text, and any other UI copy.

- Headings can end with a period or not. Either is fine, but stay consistent within a page
- Full sentences and paragraphs always get proper punctuation, including the ending period
- Descriptive text that stands alone gets a period: taglines, subtitles, tier descriptions like "For professionals and growing teams.", single-line descriptions like "For organizations that need more power and control."
- Only drop the period on items in a list, e.g. feature bullets in pricing cards
- Never use emojis anywhere. Not in headings, descriptions, buttons, labels, or any other text
