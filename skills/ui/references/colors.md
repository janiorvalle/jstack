# Colors

Use these rules when picking brand colors, accent colors, neutral palettes, text colors, and default color families.

- Never default to indigo as the brand or accent color. Only use indigo if the project already does or the user asks for it
- Never default to `gray-*` or `slate-*` for neutral and text colors. Only use them if the project already does or the user asks for them. Reach for `zinc-*` or `neutral-*` instead
