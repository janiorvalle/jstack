# Colors

Rules for brand colors, accent colors, neutral palettes, text colors, and default color families.

- Never default to indigo as the brand or accent color. Use it only if the project already does or the user asks for it
- Never default to `gray-*` or `slate-*` for neutral and text colors. Use them only if the project already does or the user asks. Reach for `zinc-*` or `neutral-*` instead
