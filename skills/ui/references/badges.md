# Badges

Use these rules for badges, tags, pills, labels, chips, status indicators, and compact metadata with icons.

- A badge with a leading or trailing icon never gets symmetric `px-*`. Use `pl-*`/`pr-*` and make the icon side's padding equal to the vertical padding: `py-1 pr-2 pl-1` (left icon), `py-1 pr-1 pl-2` (right icon)
