# Description lists

Use these rules for `<dl>`, `<dt>`, and `<dd>` content, term and detail pairs, metadata groups, and definition-style lists.

- Give `<dt>` elements a higher contrast text color and a slightly heavier weight (e.g. `font-medium`). Give `<dd>` elements regular weight and a lower contrast color. That way links inside `<dd>` can use the higher contrast color and stand out
