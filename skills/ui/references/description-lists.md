# Description lists

Rules for `<dl>`, `<dt>`, and `<dd>` content, term and detail pairs, metadata groups, and definition-style lists.

- Give `<dt>` a higher contrast text color and a slightly heavier weight (e.g. `font-medium`). Give `<dd>` regular weight and a lower contrast color, so links inside `<dd>` can use the higher contrast color and stand out
