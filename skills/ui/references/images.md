# Images

Rules for photos, thumbnails, screenshots, app mockups, product images, media frames, and image borders and outlines.

## Design rules

- Never use borders on photos or thumbnails. Use `outline-1 -outline-offset-1 outline-black/5` or `outline-black/10` if the image needs a visible edge
- Screenshots and app UI mockups get `outline-1 -outline-offset-1 outline-black/5` or `outline-black/10` on light surfaces and `outline-white/10` on dark surfaces

## Coding rules

- Use `alt=""` on images when the visible text next to them already says what they are
